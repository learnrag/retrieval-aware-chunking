# CDN (variant 3)

## Overview
This document describes the cdn used by service cluster 3.

## Policy
Static assets are served from an edge cache.
Related configuration keys are namespaced under `cdn.v3`.

## Operations
Operators should verify the cdn after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
Do not confuse this policy with legacy settings from cluster 2.
