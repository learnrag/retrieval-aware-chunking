# Metrics (variant 3)

## Overview
This document describes the metrics used by service cluster 3.

## Policy
Service metrics are scraped by Prometheus.
Related configuration keys are namespaced under `metrics.v3`.

## Operations
Operators should verify the metrics after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
Do not confuse this policy with legacy settings from cluster 2.
