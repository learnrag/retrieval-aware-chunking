# Authentication (variant 3)

## Overview
This document describes the authentication used by service cluster 3.

## Policy
Interactive logins are SSO only.
Related configuration keys are namespaced under `auth.v3`.

## Operations
Operators should verify the authentication after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
Do not confuse this policy with legacy settings from cluster 2.
