# Authentication (variant 2)

## Overview
This document describes the authentication used by service cluster 2.

## Policy
Interactive logins are SSO only.
Related configuration keys are namespaced under `auth.v2`.

## Operations
Operators should verify the authentication after each change window.
Escalation contacts are listed in the on-call roster for cluster 2.

## Notes
Do not confuse this policy with legacy settings from cluster 1.
