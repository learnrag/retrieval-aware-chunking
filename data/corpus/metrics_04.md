# Metrics (variant 4)

## Overview
This document describes the metrics used by service cluster 4.

## Policy
Service metrics are scraped by Prometheus.
Related configuration keys are namespaced under `metrics.v4`.

## Operations
Operators should verify the metrics after each change window.
Escalation contacts are listed in the on-call roster for cluster 4.

## Notes
Do not confuse this policy with legacy settings from cluster 3.
