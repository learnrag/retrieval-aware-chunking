# CDN (variant 2)

## Overview
This document describes the cdn used by service cluster 2.

## Policy
Static assets are served from an edge cache.
Related configuration keys are namespaced under `cdn.v2`.

## Operations
Operators should verify the cdn after each change window.
Escalation contacts are listed in the on-call roster for cluster 2.

## Notes
Do not confuse this policy with legacy settings from cluster 1.
