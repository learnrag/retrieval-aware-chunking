# Authentication (variant 4)

## Overview
This document describes the authentication used by service cluster 4.

## Policy
Interactive logins are SSO only.
Related configuration keys are namespaced under `auth.v4`.

## Operations
Operators should verify the authentication after each change window.
Escalation contacts are listed in the on-call roster for cluster 4.

## Notes
Do not confuse this policy with legacy settings from cluster 3.
