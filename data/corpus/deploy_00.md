# Deployments (variant 0)

## Overview
This document describes the deployments used by service cluster 0.

## Policy
Production releases use blue-green deployments.
Related configuration keys are namespaced under `deploy.v0`.

## Operations
Operators should verify the deployments after each change window.
Escalation contacts are listed in the on-call roster for cluster 0.

## Notes
