# Restore Process (variant 4)

## Overview
This document describes the restore process used by service cluster 4.

## Policy
Restore requests require approval.
Related configuration keys are namespaced under `restore.v4`.

## Operations
Operators should verify the restore process after each change window.
Escalation contacts are listed in the on-call roster for cluster 4.

## Notes
Do not confuse this policy with legacy settings from cluster 3.
