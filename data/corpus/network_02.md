# Networking (variant 2)

## Overview
This document describes the networking used by service cluster 2.

## Policy
Services run inside a private VPC.
Related configuration keys are namespaced under `network.v2`.

## Operations
Operators should verify the networking after each change window.
Escalation contacts are listed in the on-call roster for cluster 2.

## Notes
Do not confuse this policy with legacy settings from cluster 1.
