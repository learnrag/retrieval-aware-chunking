# Timeouts (variant 4)

## Overview
This document describes the timeouts used by service cluster 4.

## Policy
Upstream timeouts are set to 30 seconds.
Related configuration keys are namespaced under `timeouts.v4`.

## Operations
Operators should verify the timeouts after each change window.
Escalation contacts are listed in the on-call roster for cluster 4.

## Notes
Do not confuse this policy with legacy settings from cluster 3.
