# Logging (variant 3)

## Overview
This document describes the logging used by service cluster 3.

## Policy
Application logs are emitted as JSON lines.
Related configuration keys are namespaced under `logging.v3`.

## Operations
Operators should verify the logging after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
Do not confuse this policy with legacy settings from cluster 2.
