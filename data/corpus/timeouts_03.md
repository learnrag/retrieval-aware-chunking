# Timeouts (variant 3)

## Overview
This document describes the timeouts used by service cluster 3.

## Policy
Upstream timeouts are set to 30 seconds.
Related configuration keys are namespaced under `timeouts.v3`.

## Operations
Operators should verify the timeouts after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
Do not confuse this policy with legacy settings from cluster 2.
