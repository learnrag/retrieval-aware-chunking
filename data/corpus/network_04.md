# Networking (variant 4)

## Overview
This document describes the networking used by service cluster 4.

## Policy
Services run inside a private VPC.
Related configuration keys are namespaced under `network.v4`.

## Operations
Operators should verify the networking after each change window.
Escalation contacts are listed in the on-call roster for cluster 4.

## Notes
Do not confuse this policy with legacy settings from cluster 3.
