# Networking (variant 3)

## Overview
This document describes the networking used by service cluster 3.

## Policy
Services run inside a private VPC.
Related configuration keys are namespaced under `network.v3`.

## Operations
Operators should verify the networking after each change window.
Escalation contacts are listed in the on-call roster for cluster 3.

## Notes
